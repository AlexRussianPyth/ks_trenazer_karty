# Тренажёр карт «Каналсервис»

Анимированный тренажёр для менеджеров: районы, города в радиусе 200 км и
основные трассы вокруг Москвы и Санкт-Петербурга. HTML + JS, без сборки.

## Возможности

- 11 уровней: города-спутники (50 / 100 / 200 км), посёлки и районы
  городов-спутников, округа Москвы, районы Петербурга, трассы и шоссе
  обеих агломераций
- Геймификация: очки, комбо-множитель, жизни, таймер, звёзды за уровень,
  7 достижений, сохранение прогресса в localStorage
- Анимации: «перелёт» к найденному городу, кольца радиусов 50/100/200 км,
  конфетти, звуковые сигналы
- Дизайн по брендбуку Каналсервиса: сигнальный синий `#0041A0`,
  акцентный оранжевый `#FF4200`, шрифт Onest

## Структура

```
index.html        точка входа (одна страница)
css/style.css     стили
js/data.js        геоданные: города, округи, районы, посёлки, трассы
js/app.js         игровая логика
js/bitrix24.js    адаптер для локального приложения Битрикс24
assets/           логотип и элементы бренда (SVG)
```

## Запуск локально

Нужен любой статический сервер (из-за загрузки данных JS-модулями):

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Прямое открытие `index.html` файлом тоже работает в большинстве браузеров.

## Установка как локальное приложение Битрикс24

Приложение серверless — достаточно любого HTTPS-хостинга со статикой
(корпоративный сайт, GitHub Pages, S3 и т.п.).

1. Загрузите содержимое репозитория на HTTPS-хостинг так, чтобы
   `index.html` был доступен по адресу вида `https://example.com/ks-trainer/`.
2. В Битрикс24 откройте **Разработчикам → Другое → Локальные приложения**
   (Developer resources → Add application).
3. Создайте приложение с параметрами:
   - **Тип**: локальное приложение, без сервера («Приложение использует
     только frontend»);
   - **Ссылка на приложение**: URL `index.html` с хостинга;
   - **Область встраивания**: меню «Приложения» (или нужный placement).
4. Сохраните и откройте приложение из меню портала.

Адаптер `js/bitrix24.js` сам определит, что он внутри Битрикс24
(параметры передаются порталом через `window.name`), подключит JS API
с вашего портала и будет подгонять высоту iframe под содержимое.
Вне Битрикс24 скрипт неактивен.

## Внешние зависимости (CDN)

- Leaflet 1.9.4 (карта) + тайлы OpenStreetMap
- Шрифт Onest (Google Fonts)

Компьютеры пользователей должны иметь доступ к этим ресурсам.
